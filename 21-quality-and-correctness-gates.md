# Quality and correctness gates under optimization

Hardware for every own row: ASUS Ascent GX10 (NVIDIA GB10, SM121, compute capability 12.1, 128 GB unified memory). TP1 rows ran on one node; TP2 rows on node-1 + node-2 over a direct RoCE link; TP3 rows on node-1 + node-2 + node-3. Own rows are cited by packet date and title. "Gate set" means the deterministic API fixtures the fleet reuses: exact-string smoke at temperature 0, thinking on/off separation, strict JSON, a required tool call with bounded arguments, tool-result continuation (a distinctive nonce echoed back), no-tool, unknown-tool resistance, coding with local test vectors, malformed and oversize requests rejected with HTTP 400, vision, and a greedy logprob integrity probe. "Needle ladder" means 3-4 random markers at early, middle and late positions, exact match, cold then repeated. Upstream code is quoted at vLLM `711fc55c10a2`, SGLang `f2a1366584e1`, llama.cpp `6e60f35608ec` and ExLlamaV3 `6b84a21b6f1e` (all fetched 2026-09-23); a code line says what upstream does at that pin, not what a given lane runs. Every GitHub thread cited was re-read with all comments on 2026-09-23, and 23 first-pass statements were corrected against the primary; the corrected forms are the ones used here.

The single lesson of this page: on GB10, the failures that matter return HTTP 200, run at normal or better speed, pass a short smoke test, and often raise speculative acceptance. Speed, acceptance and averages are not correctness evidence.

## 1. What it is

Every speed optimization on a GB10 can change what a model says without raising an error: lower-precision weights (quantization, fewer bits per weight), an 8-bit or 4-bit KV cache (the model's working memory of the conversation), speculative decoding (a small drafter guesses tokens that the big model checks), prefix caching (reusing work from an earlier request), fused kernels, sparse attention (reading only selected past tokens), abliteration (editing a model so it stops refusing), a new chat template, or a clock cap. The damage is rarely total. Typical cases on record: one character slips inside a long file path, a Thai tone mark disappears, a tool argument is truncated one time in fourteen, a reasoning tier silently stops applying, or answers change only when eight requests run at once. Worse, the usual health signals move the wrong way: a model with a broken output layer agrees perfectly with its own drafter, so speculative acceptance and tokens per second both go up. A correctness gate is a fixed, versioned test a lane must pass before it serves traffic, chosen so that it fails on the specific way an optimization can break. The gates that have caught real GB10 failures are narrow: a greedy log-probability probe (read the model's confidence numbers after every restart), exact-copy fixtures (repeat a long look-alike string byte for byte), needle retrieval at several positions and depths, the same prompt fired many times at once to count distinct answers, speculation on versus off at temperature 0, and a paired comparison against the current lane on items the change is known to move. This page lists what each engine and optimization has silently broken, the fixtures that caught it, how to measure a regression without fooling yourself, the gate battery and promotion record a lane needs, and which own lanes still carry undischarged gates. Related pages: [Speculative decoding on GB10](02-speculative-decoding.md), [GEMM backends and quantization formats on SM121](09-gemm-backends-and-quant-formats.md), [KV cache and prefix caching on GB10](10-kv-cache-and-prefix-caching.md), [Sampling and the lm_head on GB10](12-sampling-and-lm-head.md), [Linear attention and hybrid layers on SM121](07-linear-attention-and-hybrid-layers.md), [Profiling protocol](14-profiling-protocol.md), [Serving agent workloads](22-serving-agent-workloads.md).

## 2. How each engine does it

No engine ships a promotion gate. Each ships pieces: a determinism mode, regression tools, controls on how strictly speculative drafts are accepted, and defaults that silently change what a gate measures (sampling temperature, EOS handling, prefix caching). The per-engine sections list those pieces, their defaults on CC 12.1, and the silent-correctness reports filed from GB10.

### vLLM

**Determinism (batch invariance).**
- `VLLM_BATCH_INVARIANT=1` turns it on (`vllm/envs.py:626-628`; the code comment says compute capability >= 9.0, while `docs/features/batch_invariance.md:18-24` says >= 8.0, beta). [Code-verified]
- On CUDA outside SM80 it disables split-K by setting `CUBLAS_WORKSPACE_CONFIG=:16:8` and `CUBLASLT_WORKSPACE_SIZE=1` (`vllm/model_executor/determinism/batch_invariant.py:1063-1077`); SM121 takes this branch, and major version 12 maps to the "sm120" tuned-matmul family (`batch_invariant_configs.py:492-503`). The tuned tile path applies only to unquantized BF16 models (`vllm/config/vllm.py:780-800`); custom all-reduce is disabled (`vllm/config/parallel.py:1083-1085`); NVFP4 linear layers are forced to CUTLASS or an emulation fallback (`vllm/model_executor/kernels/linear/__init__.py:1080-1114`). [Code-verified]
- Only five attention backends declare support: TRITON_ATTN, FLASH_ATTN, FLEX, FLASHATTN_MLA, TRITON_MLA (`vllm/v1/attention/backend.py:334`). Any mamba or GDN backend raises `RuntimeError` in batch-invariant mode (`vllm/v1/attention/selector.py:235-239`). MoE experts must declare support (`fused_moe/modular_kernel.py:566-567`: cutlass, triton, humming). [Code-verified]
- [Interpretation] None of the hybrid-GDN or sparse-MLA model classes that GB10 lanes commonly run can use this mode at the pin, so it cannot stand in for a measured determinism gate. The docs' tested-models list names Qwen3-Next-80B-A3B, a GDN hybrid, which the code at the pin would refuse (contested, §8).

**Speculative decoding: what "lossless" means.**
- The docs define three levels: theoretical losslessness up to hardware numerics, algorithmic losslessness validated by greedy-equality tests, and no guarantee of stable logprobs; batch size can change logits enough to change tokens (`docs/features/speculative_decoding/README.md:190-222`). The theory is the rejection-sampling result of arXiv 2211.17192, where acceptance at a position is 1 minus the total-variation distance between draft and target and draft quality affects only speed. [Interpretation] for the theory; vendor doc for the levels.
- `rejection_sample_method` accepts `standard`, `synthetic` (accepts drafts at a calibrated synthetic rate, so not output-preserving) and `block`; `draft_sample_method` defaults to `greedy` with `probabilistic` opt-in (`vllm/config/speculative.py:85-86, 530-550`). Model Runner V2 keeps strict rejection by default and makes probabilistic rejection opt-in (vllm#35461, merged). [Code-verified]

**Defaults that change what a gate measures.**
- A request without `temperature` takes the checkpoint's `generation_config.json` values when `--generation-config auto`, the default (`vllm/entrypoints/openai/chat_completion/protocol.py:625-685`; `vllm/config/model.py:332-340, 1816-1852`, with a startup notice). A gate that omits sampling fields is a sampled gate. PR #32723 (merged 2026-01-22) removed the implicit `temperature=0` from `vllm bench serve`. [Code-verified]
- `logprobs_mode` defaults to `raw_logprobs` (before temperature and top-k/top-p); `processed_*` modes reflect them (`vllm/config/model.py:101-106, 261-270`). A logprob gate must state the mode. [Code-verified]
- `vllm bench serve` forces `ignore_eos` for the random and timed-trace datasets (`vllm/benchmarks/serve.py:2154-2172`); offline `throughput.py` hardcodes `temperature=1.0, top_p=1.0, ignore_eos=True` (`vllm/benchmarks/throughput.py:108-116`). With `ignore_eos`, generation-config secondary EOS ids go into `_all_stop_token_ids` but not `stop_token_ids` (`vllm/sampling_params.py:696-723`); `check_stop` tests EOS, then stop ids, then length, then `min_tokens` (`vllm/v1/core/sched/utils.py:98-128`). Whether a secondary EOS still stops an `ignore_eos` request is contested (§8). [Code-verified]
- Quantized KV without per-token-head scales logs "may cause accuracy drop without a proper scaling factor" at INFO level, not as a warning (`vllm/config/cache.py:363-369`). [Code-verified]
- Prefix caching is on by default where supported; only `--no-enable-prefix-caching` disables it, and removing `--enable-prefix-caching` does not (vllm#40896). [Community-measured]
- Tool parsing: `validate_tool_names` defaults False in the parser engine config and is True for the GLM 4.7 MoE parser (`vllm/parser/engine/parser_engine_config.py:110`; `vllm/parser/glm47_moe.py:179`). The tool-calling docs say named function calling guarantees a parsable call, not a good one (docs.vllm.ai tool_calling page, fetched 2026-09-23). [Code-verified]

**Flags and env vars.** `VLLM_BATCH_INVARIANT`; `--generation-config {auto|vllm|<dir>}`; `--no-enable-prefix-caching`; `--kv-cache-dtype`; speculative-config `rejection_sample_method`, `draft_sample_method`; `--compilation-config` pass switches (`fuse_norm_quant`, `fuse_act_quant`); `VLLM_MARLIN_INPUT_DTYPE`; `VLLM_USE_V2_MODEL_RUNNER`; request `logprobs`, `prompt_logprobs`, `ignore_eos`.

**Defaults on CC 12.1.** Batch invariance off (and unavailable for GDN and sparse-MLA backends); prefix caching on; generation-config `auto`; strict rejection sampling; greedy drafting; FP8 KV only when requested, with scale 1.0 unless the checkpoint ships scales. [Code-verified] No SM121-specific test exists under `tests/v1/determinism` at the pin. [Code-verified]

**Silent-correctness reports filed from GB10** (details and numbers in §4): Marlin W4A8-FP8 activations looping on `</think>` (vllm#49546); default norm/activation-quant fusions garbling DeepSeek-V4-Flash (vllm#50773); a first FP8-KV patch on the QSA indexer reading the wrong dtype (vllm#54426, fixed by #55557); PLE short-conv state corruption under concurrent prefill with MTP configured (vllm#55357, fixed by #55375); prefix-cache hits silently dropped to zero under any speculative method on GDN hybrids (vllm#54360); GLM-5.3 NVFP4 non-ASCII corruption under concurrency (vllm#57087); QSA indexer-budget nondeterminism (vllm#54521); stop strings evaluated inside reasoning (vllm#52393, fix PR #52486 open); XGrammar "Failed to advance FSM" (vllm#53181). Upstream fixes such as the indexer tail-seed stride (vllm#57477, merged 2026-09-20) must be checked against whatever base an out-of-tree overlay pins. [Community-measured]

### SGLang

**Deterministic inference.**
- `--enable-deterministic-inference` allows attention backends ascend, fa3, fa4, flashinfer, intel_xpu, triton (`python/sglang/srt/arg_groups/choices.py:111-118`); forces the pytorch sampling backend (`arg_groups/overrides.py:978-985`); disables all-reduce fusions; restricts absorbed-MLA models further and requires SM100/SM110 for fa4 (`arg_groups/attention_hook.py:550-576`); disables the radix cache for backends outside the radix-supported set. [Code-verified]
- Verification commands ship in the docs: `python3 -m sglang.test.test_deterministic --test-mode single|prefix|radix_cache` (`docs/docs/advanced_features/deterministic_inference.mdx:200-214`). The speculative "UNO" mode cannot combine with deterministic inference, grammar decoding, returned logprobs or logit bias (`speculative_decoding.mdx:515-522`). [Code-verified]
- On GB10 the flag reduced 32 identical temperature-0 requests from 8 distinct completions to 1 on a dense BF16 model (sglang#36291). The same reporter says it was ineffective on an NVFP4 W4A4 hybrid-Mamba checkpoint with DFlash2 while reporting itself enabled, but that evidence came from scored-item flips, the reporter's weaker instrument; the distinct-completion probe with the flag on was not run. [Community-measured]

**Speculative acceptance strictness.** `speculative_accept_threshold_single` and `speculative_accept_threshold_acc` default 1.0 (strict); any lower value relaxes acceptance. `speculative_use_rejection_sampling` defaults False and requires topk=1 (`python/sglang/srt/arg_groups/fields/spec.py:104-114`). [Code-verified] SGLang STANDALONE speculation performs no startup check that draft and target vocabularies match (sglang#24051, reporter statement; closed for inactivity). [Community-measured]

**Sampling defaults.** `--sampling-defaults` defaults to `model`, so omitted fields come from the checkpoint (`arg_groups/fields/serving.py:221-227`). The benchmark client defaults `ignore_eos` on and `temperature` 0.0 unless the body sets them (`python/sglang/benchmark/serving.py:258-286`). [Code-verified]

**Structured output.** Exactly one of `json_schema`, `regex` or `ebnf` per request, default backend XGrammar (SGLang structured-outputs doc, fetched 2026-09-23). The guarantee is format, not content (§4). [Code-verified]

**Quantized KV reference table.** The repo doc reports Qwen3-235B-A22B GSM8K flat across BF16, FP8 and FP4 KV while AIME25 falls (`docs/docs/advanced_features/quantized_kv_cache.mdx` at `f2a1366`, "preliminary", from PRs #10078 and #12612). [Community-measured]

**Flags.** `--enable-deterministic-inference`; `--speculative-accept-threshold-single/-acc`; `--speculative-use-rejection-sampling`; `--sampling-defaults {model|openai}`; `--grammar-backend`; `--kv-cache-dtype`; `--disable-radix-cache`.

**Defaults on CC 12.1.** Deterministic off; strict acceptance (1.0); sampling from the model's generation config; radix cache on; XGrammar. [Code-verified]

**Silent-correctness reports filed from GB10** (§4): every output token id 0 on a MiniMax-M3 W4A16 checkpoint that was correct on vLLM on the same nodes (sglang#38143); an fp8 `wo_a` absorb GEMM ~25% wrong when `DEEPGEMM_SCALE_UE8M0` is false, reachable only on checkpoints re-blocked to 128x128 (sglang#39193); DFlash2 greedy drift at concurrency 8 on packed-FP4 heads (sglang#36548); a chunked-prefill / radix-insert race that poisons every later request sharing a prefix (sglang#38319). The loader class behind the own broken-head incident is compressed-tensors mixed-precision recipes not being recognised (sglang#16276, closed stale). For GB10 long-context sparse decode the correct fix is the exact-SM121 Triton packed-varlen fallback (sglang#36845, merged 2026-08-30), not the exact-SM120 route of sglang#36806, which deliberately excludes SM121 because forcing GB10 through it corrupted long contexts. [Community-measured]

### llama.cpp and forks

**Regression and numerics tools** [Code-verified at `6e60f35`]:
- `llama-results --check` compares outputs to a stored file with NMSE tolerance 1e-6 (`tools/results/README.md`).
- `test-backend-ops` asserts that backends agree on each GGML op (`tests/test-backend-ops.cpp:1-5`).
- `llama-perplexity --kl-divergence-base / --kl-divergence` reports mean KLD, PPL ratio, delta-p percentiles, RMS delta-p and same-top-p (`tools/perplexity/README.md:12-34`; reference table at `:100-128`).
- Tests for recurrent-state rollback, GBNF validation, JSON-schema-to-grammar and chat parsers live under `tests/`.

**Nondeterminism and speculation defaults.** The server's `cache_prompt` defaults true and the README warns that logits are not guaranteed bit-identical across batch sizes (`tools/server/README.md:587`). Speculation defaults `n_max` 3 and `p_min` 0.0 (`common/common.h:326-330`; `--spec-draft-p-min`, `common/arg.cpp:4193-4196`). [Code-verified] The default `p_min` was 0.75 until 2026-05-19 (graphometer.ai). [Community-measured]

**EOS.** `ignore_eos` is implemented as end-of-generation logit biases (`tools/server/server-schema.cpp:474-484`); PR #21203 added `tests/unit/test_ignore_eos.py`. [Code-verified]

**Flags.** `--spec-draft-p-min`, `--parallel`, `--cache-prompt`, `--grammar`, `--json-schema`; build with `-DCMAKE_CUDA_ARCHITECTURES=121` on GB10 (llama.cpp#27217 reporter).

**Defaults on CC 12.1.** No SM121-specific numerics gate in the tree; `cache_prompt` on; ungated drafting (`p_min` 0.0). [Code-verified]

**Silent-correctness reports filed from GB10** (§4): a server image built for sm_120 emitted only `?` tokens on sm_121 at normal speed for one Q4_K_M model while another model on the same image was coherent (llama.cpp#23010; the "close-enough cubin" explanation is a third-party commenter's, not a maintainer's, unconfirmed, closed stale); DeepSeek-V4-Flash exact-copy corruption on a 2-node RPC split (llama.cpp#28132); DeepSeek-V4-Flash GPU-expert garbage that depends on quant type (llama.cpp#25582, original reporter on RTX 3090, GB10 commenter; closed stale); multi-sequence recurrent-state rollback on Qwen 3.8 Flash Next (llama.cpp#28019; #28123 merged but a dirty-context rollback test still fails on later master); `tool_choice: "required"` accepted but not enforced for templates flagged `supports_preserve_reasoning` (llama.cpp#27217); an 8-byte `<think>\n` tail discarding an 11.7K-token completed generation (llama.cpp#27733). [Community-measured] Own: a fork wrapped a valid `json_object` in Markdown fences (§4). [Measured]

### ExLlamaV3 in vLLM

- [Code-verified] Upstream vLLM at `711fc55` has no EXL3 quantization method (only the older GPTQ `exllama` kernel). EXL3 serving in vLLM on GB10 is an out-of-tree overlay, so correctness depends on the overlay's pinned vLLM base plus its patches; upstream fixes must be checked against that base.
- [Code-verified at `6b84a21`] ExLlamaV3 ships the richest local quality tooling of the four engines: `eval/model_diff.py` (PPL for A and B, KL in both directions, top-K hit and A-vs-B top-K agreement, and `--cache_quant_sweep`, a simulated KV-quantization KLD table; `:472-489`); `eval/qbench.py` (KLD against BF16 on held-out traces with per-token vectors, so tool-call rows can be sliced from prose; `doc/optimize.md:264-270`); `eval/spec_decode.py` (per verification round: mean accepted draft tokens, mean drafted window, and acc_rate = accepted / (accepted + rejected); `:85-135`); plus `ppl.py`, `humaneval.py`, `mmlu.py`, `ifbench.py`, `longctx.py`, `bbeh_mini.py`, `diversity.py`. No SM12x-specific code path exists in the repo.
- [Community-measured] Its bitrate optimizer can produce a recipe with worse KLD than the uniform baseline (turboderp-org/exllamav3#108, closed 2026-09-05), so an optimized quant needs its own KLD check. Its `ds4` prompt format looked up an ASCII `<|User|>` instead of the full-width token, so that stop condition was silently dropped and EOS was the only stop; the reporter observed no runaway (exllamav3#279, closed 2026-08-11).
- [Community-measured] The community two-node GB10 GLM-5.3-Flash EXL3 recipe (MiaAI-Lab/GLM-5.3-Flash-EXL3-2x-DGX-Sparks at `71962cd`) carries its own gates: a third-party teacher-KLD panel for weight formats (§4); a PROVISIONAL KL proxy for its dense-FP8 projections and a proposal gate of at most +0.005 nats over the 0.0246 baseline for further FP8 GEMMs (`README.md:141`; `docs/improve-prefill.md:162-167`); a seven-level qualification ladder that separates answer correctness from drafter validity (`docs/DESIGN-apc-per-group-retention.md:520-570`, §6); a kernel lab with a NumPy reference oracle; and the warning that "cache-hit correctness tests do not establish universal cold/cached output equality" (`docs/apc-retention-qualification.md:152-156`).
- [Measured] Own EXL3-in-vLLM lanes: a 2-bit DeepSeek build was faster and failed agent gates; a 3-4-bit build passed a single tool gate and failed the loop; GLM grouped-expert kernels passed numerical tests and changed-data graph replay before full gates (§4).

### TensorRT-LLM (status)

Guided decoding runs through XGrammar or LLGuidance; tech blog 12 argues that grammar constraints on the target suffice under speculation because illegal drafts are rejected at verification; integration tests cover JsonModeEval with Eagle3 at `max_draft_len: 3` (NVIDIA/TensorRT-LLM#6704). It has no `ignore_eos`; benchmarks emulate it with `min_length` and `end_id`. No SM121 correctness report was found. [Code-verified per repo docs, fetched 2026-09-23]

## 3. What is different on GB10 / SM121

- [Community-measured] **Silent numerics at HTTP 200 are reported specifically from GB10, across all three open engines.** Token id 0 for every output (SGLang), `?` for every output (llama.cpp sm_120 image on sm_121), a `</think>` loop from a W4A8-FP8 activation switch (vLLM), garbled text from default fusions (vLLM), ~25% GEMM error from truncated activation scales (SGLang, re-blocked checkpoints only), character-level exact-copy corruption (llama.cpp), and non-ASCII corruption only under concurrency (vLLM). None raised an error; several ran at normal speed. §4 has the numbers.
- [Community-measured] **Fixes for SM120 do not transfer to SM121 by default.** SGLang's exact-SM120 sparse-decode gate (sglang#36806) excluded SM121 on purpose: forcing GB10 through that route produced token-0 output in 1/4 runs at 120K rising to 4/4 at 210K (sglang#36806), while the sglang#36845 body reports 32/32 token id 0 at 120K-210K; the counts come from different instruments on the same mechanism (see [Attention backends on SM121](06-attention-backends-sm121.md)). GB10 has its own exact-SM121 Triton fallback (sglang#36845). The SM120 data in sglang#36537 (50-100% corrupted eager generations, 0/42 after the gate) are RTX PRO 6000 results.
- [Community-measured] **A build that targets sm_120 can load on sm_121 and compute wrong** at normal speed (llama.cpp#23010; mechanism unconfirmed). Build with the architecture set to 121 and run the integrity probe on every image.
- [Code-verified] **No engine determinism mode covers the model classes GB10 lanes run.** vLLM batch invariance refuses mamba/GDN backends and supports only five dense or MLA attention backends; SGLang's fa4 deterministic path requires SM100/SM110. Determinism must be measured (distinct-completion probes), not switched on.
- [Community-measured] **Sparse-attention indexers are a GB10 correctness surface.** Above the QSA indexer budget, 5 identical greedy requests give 3-4 distinct completions with damaged Thai tone marks (vllm#54521, 2x GB10). On a three-node GLM-5.3-Flash EXL3 deployment with the published `index_topk` 2048, tool-call string arguments slipped single characters above ~32K prompt tokens on 11/30 fresh turns while needle tests passed; only `index_topk` 8192 moved it (§4). Indexer routes and dispatch: [Attention backends on SM121](06-attention-backends-sm121.md) and [Engine dispatch maps](16-engine-dispatch-maps.md).
- [Community-measured] **Acceptance on GB10 is noisy enough that small deltas mean nothing.** A 1-ulp kernel change moved MTP acceptance by +6.6, +10.4 and -3.8 points across three prompts (vllm#54426), and a -10.6% relative acceptance loss reported on a GB10 TP2 lane inverted on a newer base (vllm#49927). Book acceptance deltas under ~10 points only with per-prompt spread.
- [Measured] **Uncalibrated FP8 KV is common on own GB10 lanes.** Two own lanes run FP8 KV at the default scale 1.0: one because a loader dropped the shipped scales, one because the checkpoint ships none. Gates and retrieval pass; that does not show equivalence to BF16 KV, and no own BF16-KV control exists.
- [Measured] **Deep-context gates are affordable but slow.** Unified memory lets lanes serve 524K-1M tokens, and needle ladders to 1M pass on the own TP3 lane, but a cold 524,036-token request took 499.3 s on the TP2 dense-FP8 lane and an 85K three-needle request 56.7 s cold. [Interpretation] A calibrated judge A/B of 220 prompts x 2 references per arm at the fleet's ~40-60 tok/s single-stream is a multi-hour job, not a multi-day one; a 1M ladder with repeats is a multi-hour job on its own.
- [Interpretation] **GB10 lanes stack optimizations.** A typical lane combines 4-bit or FP4 weights, FP8 projections, FP8 KV, speculative decoding at depth 5-8, prefix caching, a patched indexer and an out-of-tree overlay. Every gate must run on the full stack as served; a component that passes alone says little about the combination (the MTP + prefix-cache interaction in §4 is the reference case).

## 5. Levers, ranked

Here a lever is a gate or practice, and "gain" means detection power: which documented failures it would have caught, at what cost. Ranked by how many GB10 failure cases it catches, times how cheap it is to run on every change. [Proposed] applies to every lever as a promotion requirement; the evidence each rests on is graded inline.

1. **Logit-integrity gate after every relaunch, plus a header check of the head and scales.** Applies to: every engine x every model x every topology. Gain: catches the broken-head class (top-1 logprob 0.0 with runners-up near -29,696 [Measured]), token-0 and all-`?` outputs (sglang#38143, llama.cpp#23010 [Community-measured]), and impossible first tokens from a poisoned cache (sglang#38319 [Community-measured]). Cost: seconds: one 8-token greedy probe with logprobs (state `logprobs_mode`), one 32-token warm-up that rejects token id 0, a single repeated character, or an out-of-vocabulary id, and a header read that refuses `lm_head.weight_scale` where the engine cannot apply it. Risk: none; it cannot see subtle drift. Smallest falsifying experiment: replay the known-broken export through the probe; the lever is worthless if the probe passes it.
2. **Drafter validity at production depth.** Applies to: vLLM, SGLang, llama.cpp x any speculative method x any topology. Gain: catches drafter config drift (0.00 acceptance at depth, CUDA assert at 264,384 [Measured]), vocabulary mismatch (sglang#24051 [Community-measured]) and a weight-scale bypass that shows only as lower acceptance (vllm#51581 [Community-measured]). Cost: read the drafter's rope, max length and vocabulary at launch; one acceptance probe at the served depth, not only short prompts; a live acceptance canary. Risk: acceptance is noisy (±10 points from a 1-ulp change [Community-measured]); use bands with per-prompt spread. Smallest falsifying experiment: a probe at 40K and at the served depth on a known-good lane; if acceptance at depth matches short-prompt acceptance within spread, depth probes add nothing for that lane.
3. **Exact-copy fixtures beside the needle ladder.** Applies to: every engine x long-context and quantized models x every topology; mandatory for sparse-indexer models (DSA, QSA; routes on [Attention backends on SM121](06-attention-backends-sm121.md) and [Engine dispatch maps](16-engine-dispatch-maps.md)). Gain: caught 0/40 byte-exact echoes on llama.cpp while prose read fluent (llama.cpp#28132), 11/30 bad tool-argument turns while needles passed (vllm#51782) [Community-measured]; own aggregate needle passes coexisted with late-position misses and a dropped doubled letter [Measured]. Cost: a 65-character command echo, a look-alike file-path tool argument above ~32K, a non-ASCII wall under C4-C8, and a replay of real long agent sessions (a synthetic look-alike fixture read 0/30 where the real replay read 11/30 [Community-measured]). Risk: replays need privacy handling. Smallest falsifying experiment: run the fixtures on a lane with a known exact-copy defect (for example `index_topk` 2048 on the GLM class) and on the same lane at 8192; if the fixture cannot separate them, it is not sensitive enough.
4. **Concurrency probes: distinct completions and spec on/off at C8.** Applies to: every engine x hybrid-GDN, NVFP4 and speculative lanes x every topology. Gain: catches batch-dependent failures invisible serially: 111/304 wrong at C8 vs 0/100 serial (sglang#36548), 5/10 corrupt pairs at c=8 (vllm#55357), 8-80 U+FFFD under concurrency (vllm#57087) [Community-measured]. Cost: N identical T=0 requests fired together, distinct completions counted and each checked for content damage; the same at in-flight 1; a control arm that must show more than one distinct completion (probe validity); never use scored items as the instrument, because uniform failure looks deterministic (sglang#36291). Risk: near-tie divergence is not corruption; judge by content (tone marks, glyphs, wrong answers), not by distinct count alone. Smallest falsifying experiment: the four-item ordering probe, serial vs C8, spec on vs off, 100 attempts each, on the lane in question.
5. **Temperature-0 token diff for "output-neutral" changes.** Applies to: every engine x every model x clock caps, TP-degree changes, graph capture, fusions, draft-vocabulary slicing, cache features. Gain: turns an assumption into a measurement; own records inferred neutrality three times without a diff [Measured gap]; a fusion A/B was void because zero patterns were replaced (vllm#50773 [Community-measured]). Cost: a fixed 100-200-prompt set, one run per arm, first-divergence position and top-2 logprob gap recorded; plus cold-vs-warm logprob equivalence and an A->B->A prefix-cache probe for cache features. Risk: batch and graph changes legitimately move near-tie tokens; expect some divergence and investigate content, not byte identity. Smallest falsifying experiment: diff two cold boots of the same lane; if their divergence rate equals the change's, the change is inside the noise floor.
6. **Pin sampling, EOS and the reasoning tier on the wire.** Applies to: every engine x reasoning models (sampling defaults: [Sampling and the lm_head](12-sampling-and-lm-head.md)). Gain: prevents three measured traps: a high-effort benchmark that ran at default effort (78/198 zero reasoning tokens [Measured]), a template that ignored `enable_thinking=false` (4/7 gates [Measured]; ~8 GPU-days wasted in a community sweep [Community-measured]), and stop strings firing inside reasoning (score 0.98 -> 0.66-0.84, vllm#52393 [Community-measured]). Cost: explicit `temperature` and tier in every request; record reasoning tokens and `finish_reason` per response; budgets sized to answer plus tier. Risk: pinning changes production behaviour for clients that relied on model defaults; benchmark and serving settings are separate decisions. Smallest falsifying experiment: one request per tier, reasoning-token count read back; the lever is unnecessary only if every tier differs as intended.
7. **Enough attempts for low-rate failure classes, and Pass^k for agent loops.** Applies to: tool continuation, strict JSON, agent loops. Gain: a 3/41 tool-echo truncation [Measured] is invisible at 3 attempts; Pass^3 fell up to 24 pp while Pass@3 held (arXiv 2604.06132 [Community-measured]). Cost: 40 attempts per thinking mode for each low-rate class. [Interpretation] With 0 failures in 40 the one-sided 95% upper bound on the failure rate is about 7.5% (rule of three); proving 1% needs about 300 clean attempts. Risk: time. Smallest falsifying experiment: rerun the 41-attempt echo on the incumbent and with MTP off; if all arms show 3/41, the failure is not caused by the change under test.
8. **KLD, flips and top-K agreement for quantization, KV dtype and abliteration.** Applies to: llama.cpp (`llama-perplexity --kl-divergence`), ExLlamaV3 (`model_diff`, `qbench`, `--cache_quant_sweep`), vLLM (`prompt_logprobs` teacher-forced comparison) x any model. Gain: accuracy can hold while 13.6% of answers flip (arXiv 2407.09141) and 78.7% of completions change while graded facts hold (quant-truth) [Community-measured]; an optimizer can pessimize KLD (exllamav3#108). A community recipe gates a numerics change at +0.005 nats over its 0.0246 baseline [Community-measured precedent]. Cost: one teacher pass on a held-out set per arm; tool and prose slices separately. Risk: KLD is teacher-forced and per position, not a task score; pair it with a task gate. No own KLD exists yet. Smallest falsifying experiment: FP8 KV vs BF16 KV on one lane with `prompt_logprobs` over 50 long prompts; if KLD is below the noise of two BF16 runs, KV precision is not the lane's risk.
9. **A hard slice that the change actually moves.** Applies to: KV precision, weight quantization, reasoning-tier changes. Gain: GSM8K stayed flat across BF16, FP8 and FP4 KV while AIME25 fell 0.7733 -> 0.6000 (SGLang doc); 3-bit cost 0.1 on arithmetic vs 1.1 on multi-step math (arXiv 2609.18005); 128K NIAH fell to 13% on a broken FP8 path (Hopper) [Community-measured]. Cost: an AIME-class or multi-step set plus a deep needle set at the served length. Risk: small hard sets have wide intervals; size them (lever 11). Smallest falsifying experiment: run the hard slice and an easy set on FP8 vs BF16 KV; if both move equally, the hard slice adds nothing.
10. **Live acceptance canary with abort bands.** Applies to: any speculative lane in production. Gain: a broken head showed acceptance p90 at the block size on T=1.0 prose [Measured]; a vendor fleet terminates and retries when `spec_accept_length` stays below 1.4 after 128 tokens or `spec_accept_rate` exceeds 0.96, with garble tracking low accept length and repetition tracking high accept rate (z.ai "scaling pain" post, fetched 2026-09-23 [Community-measured practice]); the own canary exits 1 on a template regression [Measured]; its acceptance-drop exit is configured but not exercised. Cost: a 5-minute metrics scrape. Risk: acceptance is a health alarm, not a quality measure (Spearman 0.19-0.25 with judged loss [Community-measured]). Smallest falsifying experiment: inject a known template regression on a staging boot; the canary must exit non-zero within one interval.
11. **Paired, pre-registered quality A/B with a calibrated judge.** Applies to: every quality claim for a quantization, abliteration, template or runtime change. Gain: the only lever that measures quality rather than breakage; a calibrated design uses two samples from the unmodified model (dual reference), requires their judged difference to read zero (exchangeability null), runs a strict-spec arm that must read zero (implementation null, which caught two defects), adds positive controls with known losses, and tests a pre-registered ±0.3 bound on a 7-point scale by TOST (arXiv 2609.18005 [Community-measured]). Cost: 40 prompts per domain (60 for code) for ±0.3, 220 pooled for ±0.11; for binary items, [Interpretation] a paired McNemar test of a 5 pp difference at 15% discordance, alpha 0.05, 80% power needs roughly 470 items; clustered standard errors can be over 3x naive (arXiv 2411.00640). Risk: a hosted judge sees private prompts; a local judge's exchangeability null has never been measured on GB10 (§8). Smallest falsifying experiment: the exchangeability null alone: judge two samples of the incumbent against each other on 40 prompts; if it does not read zero, no A/B result from that judge is interpretable.
12. **Schema-soundness and thinking-mode gates for structured output.** Applies to: every engine x grammar backends x reasoning models (structured output per engine: [Sampling and the lm_head](12-sampling-and-lm-head.md)). Gain: invalid instances accepted by grammar engines (XGrammar 1,368, llama.cpp 649 on MaskBench, old versions) and grammars that hold while content changes (sglang#2216) [Community-measured]; strict JSON failed under thinking and passed with thinking off on an abliterated model, and a fork fenced `json_object` [Measured]. Cost: a schema-suite run of the served grammar backend version once per upgrade; strict JSON gates with thinking explicitly on and off. Risk: none. Smallest falsifying experiment: the lane's strict JSON gate 10/10 with thinking on and off; if both pass on the served build, the thinking-off rule can be relaxed for that lane.
13. **Engine determinism modes.** Applies to: vLLM batch invariance (dense and MLA backends only) and SGLang deterministic inference (dense BF16 confirmed on GB10). Gain: 8 -> 1 distinct on dense BF16 [Community-measured]. Cost: throughput and, on SGLang, the radix cache. Risk: vLLM refuses GDN hybrids [Code-verified]; SGLang was reported ineffective on NVFP4 hybrid + DFlash2 on a weaker instrument [Community-measured]. Use for evaluation boots only, and verify with lever 4. Smallest falsifying experiment: flag on vs off, 32 identical T=0 requests, distinct-completion count with a must-fail control.
14. **Keep speculative acceptance strict (anti-lever).** Applies to: SGLang accept thresholds, vLLM `synthetic` rejection, judge or lenient acceptance. Gain: none for correctness; relaxed acceptance is lossy by design (HumanEval 86.6% -> 80.4% with a judge head [Community-measured]). Keep SGLang thresholds at 1.0 and vLLM `standard`; any relaxation is a quality change and goes through lever 11. Smallest falsifying experiment: not applicable; this is a default to protect.

## 6. Protocol

The protocol an agent runs before promoting any change to a lane, and after every relaunch. It is grounded in §4 and in the own incidents in §7. See also [Profiling protocol](14-profiling-protocol.md) for speed measurement and [Speculative decoding on GB10](02-speculative-decoding.md) for acceptance measurement.

**Preconditions (fleet rules, all mandatory).**
- No memory overcommit: at least 8 GiB MemAvailable on every rank before a start, and a warm floor of at least 5 GiB on every rank after the longest qualified prefill; KV pin raises of at most 1.5 GiB per boot (see [Memory on unified memory](11-memory-on-unified-memory.md)).
- All [entry-page](README.md) rules apply, in particular: greedy logprob probe after every relaunch; discard the first request and warm every shape; unique nonce at token 0 with zero cached tokens asserted from the usage block; every rank at the same clock cap with no latched rank; the selection line on every rank; ≥3 reps with a closing A/B/A; MemAvailable every 1-2 s and zero NV_ERR_NO_MEMORY/Xid; no reboot without per-node permission. For this page that means in particular `MemAvailable` every 1-2 s with an Xid count during 1M ladders, a nonce with zero cached tokens on every cold arm, the same clock cap with no latched rank on every rank, and the backend selection line on every rank.
- One variable per boot. A head swap, a KV-dtype change, a draft change and a template change are four boots.
- Stop traffic when MemAvailable falls below 4 GiB on any rank; preserve the engines.
- Clean window: no co-tenant GPU work, builds, other benchmarks or live agent traffic; discard any pass that overlapped outside requests (own: ~90 outside requests invalidated one base pass).
- Restart A/Bs with the image and recipe pull skipped, so both arms run identical bits.
- Never restart a serving gateway or agent front-end as part of a gate run; if the change needs one, stop and hand that step to the operator. Never `pkill -f` a pattern that matches your own shell.
- Freeze the harness: harness fixes are separate changes with their own record; the harness version is part of the packet.

**Step 0: integrity (every relaunch, before any other number).**
1. Header check: head dtype and scale tensors present and loadable; the boot log shows the head and KV scales bound (no "not found in params_dict").
2. Greedy logprob probe ("The capital of France is", 8 tokens, logprobs 5, `logprobs_mode` recorded): top-1 in O(-1) to O(-20) with runners-up a few nats below.
3. Warm-up of 32 tokens on three prompts: no token id 0, no single repeated character, no id outside the vocabulary, and no NaN or inf in returned logprobs.
4. Path-taken check for kernel or fusion changes: the log line that proves the path ran (for example "Replaced N patterns" with N > 0). A change whose path did not run is not tested.
5. Drafter check for speculative lanes: drafter rope and max length match the target's served context; vocabulary identity with the target.
Any failure voids the boot. Do not run quality batteries on a boot that failed step 0.

**Step 1: pick the tiers for the change class.**

| change class | required tiers |
|---|---|
| relaunch, no change | T0 |
| kernel, fusion, clock cap ([Clocks, thermal, power](13-clocks-thermal-power.md)), TP degree, graph capture, scheduler ("output-neutral") | T0, T1, T3, T6 |
| speculation (method, depth, draft vocabulary, drafter checkpoint) | T0, T1, T2 at served depth, T4, T6 |
| weights (quantization, abliteration, checkpoint swap) | T0, T1, T2, T5, T6; add T4 if speculation is on |
| KV dtype or scales | T0, T1, T2 with a BF16-KV control arm, T5 hard slice, T6 |
| prefix caching, chunked prefill, cache retention | T0, T1, T3 (A->B->A, cold-vs-warm), T6 |
| template, parser, reasoning tier, stop handling | T0, T1 at every tier, malformed-output check per tier, T5 if a tier policy changes |
| sparse-attention indexer parameters | T0, T2 exact-copy above the indexer budget, T3 distinct-completion sweep across the budget |

**Step 2: the tiers.**
- **T1 function.** The gate set with thinking explicitly on and off, every request carrying explicit `temperature` and tier; the seven-call agent loop and the real agent-client path, reported separately (a single native tool pass predicted neither [Measured]); 40 attempts for each low-rate class (tool-result echo, strict JSON), since the pass gate needs 0 failures in 40; output budgets sized to answer plus tier. Forced-length (EOS-ignored) rows are throughput-only and never scored.
- **T2 retrieval and exact copy.** Needle ladder to the served depth with 3-4 fresh random markers at early, middle and late positions, cold and repeated, exact match; late positions at short depth too (a near-1M pass coexisted with late-position misses at 20K [Measured]). Add a 65-character echo, a look-alike file-path tool argument above ~32K, a non-ASCII wall at C4-C8, and a replay of real long agent sessions.
- **T3 equivalence.** Temperature-0 token diff on a fixed 100-200-prompt set against the incumbent, with first-divergence position and the top-2 logprob gap at that position; cold-vs-warm logprob equivalence (max |delta logprob| at most 3x the cold-vs-cold floor, position-0 token identical, the community ladder's L6); an A->B->A prefix-cache probe; a distinct-completion probe (N identical T=0 requests in flight at once, plus in-flight 1, plus a control arm that must show more than one distinct completion). The community ladder calls its L6 "necessary, not sufficient": a drafter reading zeroed KV still yields byte-identical target output, only slower. Pair T3 with T4's acceptance band.
- **T4 speculation.** Spec-on vs spec-off greedy agreement on the fixed set at the served precision, recorded, not gated on byte identity (47.7-97.3% agreement has been measured for correct implementations [Community-measured]); investigate divergence in the first 32 tokens or any content damage. Acceptance per task class with per-prompt spread; alarm on p90 at the block size on T>0 prose, or mean accept length below 1.4 after 128 tokens. Serial vs C8 ordering probe with spec on and off.
- **T5 quality A/B.** Pre-registered: the metric, the smallest effect of interest, the sample size and the decision rule are written before the first run. Binary items: paired McNemar on per-item outcomes. Judged items: dual reference, exchangeability null, implementation null, TOST on a stated bound (±0.3 on a 7-point scale needs ~40 prompts per domain). Where logits are available, KLD and top-K agreement on held-out traces with tool and prose sliced separately (community precedent: at most +0.005 nats for a numerics change). A hard slice the change moves (AIME-class for KV and quant). Abliteration: a refusal panel kept separate from the correctness panel.
- **T6 soak and recovery.** Mixed C4-C8 soak (own practice: 10-60 minutes); after any degenerate output, one unrelated clean follow-up request must be clean (a degenerate run once poisoned later unrelated requests until restart [Community-measured]); memory warm floor held.

**Record (the packet and lane card carry all of these).** Engine, version and commit; the overlay and its pinned base; the one-line diff; checkpoint revision and quantization; head dtype and scale source; KV dtype and scale source (shipped, calibrated or default 1.0); speculative method, depth, drafter revision, draft vocabulary, rejection and draft-sample methods; attention backend actually selected (from the log); prefix caching on or off; `max_model_len`; tool parser; chat template hash; structured-output backend and version; sampling fields actually sent; `logprobs_mode`; harness version; per tier: fixture list, attempts, passes, failures with verbatim output, `completion_rate` (infrastructure failures unscored); a config fingerprint so runs compare only when it matches (tool-eval-bench practice); separate compile and Triton cache roots per candidate (vLLM's `compute_hash()` was reported not to key on model source, vllm#49927); and every gate still undischarged, by name, with the reason.

**Pass gate.**
- T0 passes on every boot of every arm.
- T1: 100% of deterministic gates; 0 failures in 40 attempts for each low-rate class, or the incumbent shows the same rate.
- T2: every depth x position exact, cold and repeated; exact-copy fixtures 0 slips.
- T3: token-diff divergence no larger than the cold-vs-cold floor of the incumbent; L6 bound met; A->B->A identical; distinct-completion count no worse than the incumbent's at the same in-flight, with the control arm valid.
- T4: acceptance inside the incumbent's band with spread; no early divergence with content damage; C8 ordering probe no worse than spec-off.
- T5: the pre-registered decision rule, as written. An inconclusive result is inconclusive, not a pass: record the gate as undischarged. Own design precedent: a difference under 5 pp with overlapping CIs is inconclusive; promote only if non-inferior to the incumbent with all guardrails passing (fabrication, malformed tool/JSON, missing final, retry storms, timeouts).
- T6: 0 failures in the soak; clean follow-up; memory floor held.
- [Interpretation] A threshold must be resolvable by its sample: "FP8 KV within 3 pp of BF16" cannot be tested with 3 runs per depth (granularity 33 pp); with 3 runs the operative rule is "no depth where FP8 is 0/3 while BF16 is at least 2/3".

**Promotion.** A lane is promoted only with every required tier passed, or with each undischarged gate named on its lane card. Own records show three promotions ahead of the gate [Measured]; the lane card is where that stays visible.

**Rollback.** Revert the one changed line (checkpoint, KV dtype, speculative config, template, flag or overlay), boot with the pull skipped, rerun T0 and one frozen T1 subset, and confirm the incumbent's recorded results. If a degenerate output was served, clear the prefix cache (or restart all ranks) and send one unrelated clean request before reopening traffic.

## 7. Anti-patterns and known-bad

- [Measured] **A broken model looked like the best lane.** A dropped lm_head scale made greedy top-1 logprob 0.0, sampling hard argmax, and speculative acceptance p90 equal to the block size, because drafter and verifier shared the broken head and agreed with each other. Its prose speed (46.3 tok/s) beat MiaAI-Lab's 25.4. Every speed row and a quality battery were withdrawn. High acceptance on free prose at T>0 is an alarm, not a win.
- [Measured] **Scoring quality on a model that failed integrity.** A quality battery run on the broken head had to be discarded. Integrity gates come first.
- [Measured] **Short probes certified a speculative lane.** Acceptance was 3.00/3 on short probes and 0.00 on live traffic averaging 245K prompt tokens, because a runtime rope override never reached the drafter; a sibling lane crashed just past the drafter's native window. Measure acceptance at production depth and watch it live.
- [Measured] **An aggregate needle pass taken as retrieval quality.** A 2-bit build passed a 943,326-token three-needle request while missing both late needles at 20K and failing the tool loop 0/7. [Community-measured] Needles passed while 11/30 real long agent turns carried single-character slips in tool arguments (vllm#51782), and 0/40 exact echoes coexisted with fluent prose (llama.cpp#28132).
- [Measured] **A native tool-call pass taken as agent readiness.** Two EXL3 builds passed the single tool gate and then produced 1 valid call and 0/7 valid calls in the strict loop.
- [Measured] **Output caps manufactured failures.** A 32-token needle cap cut every UUID to a correct prefix; a 32-token smoke was eaten by forced reasoning; a 128-token JSON gate came back empty under thinking; a forced seven-call harness truncated valid final calls; an 8,192-token client cap truncated real replies. A capped answer is a harness failure until proven otherwise.
- [Measured] **Harness false negatives and positives.** A valid named-tool `finish_reason: stop` rejected; a nested usage field rejected; non-empty reasoning asserted on a trivial tool task; a stdout-substring oracle that matched the echoed prompt; a stream without usage counted as success; a diagnostic run logged "passed"; an invented cache-hit threshold. Validate against the pinned API contract and keep harness fixes out of model A/Bs.
- [Measured] **Forced-length fixtures scored for quality.** EOS-ignored runs emitted tool-call markers past the natural end of short prompts. [Community-measured] A GB10 speed sweep picked AWQ over FP8 on an `--ignore-eos` random-prompt bench that could not see an 18-vs-20 arithmetic error (rikkarth.com); `ignore_eos` also changes the workload itself (mean output length depends on it). Record `completion_tokens`, never assume `max_tokens`.
- [Measured] **A requested reasoning tier that was never applied.** A high-effort GPQA run used zero reasoning tokens on 78/198 answers; a shim and an alias pinned thinking off; an upstream template ignored `enable_thinking=false` (4/7 gates). [Community-measured] A community quant sweep spent ~8 GPU-days at the wrong tier. Verify the tier on the wire before any tier comparison.
- [Measured] **Template edits judged only on cache behaviour.** Moving the effort directive to the prompt tail produced 9/20 malformed High-tier completions. Every template change gets a malformed-output check at each tier.
- [Community-measured] **Stop strings inside reasoning.** Client `stop` strings evaluated in the reasoning segment decapitated 8-15/50 GSM8K answers on 2x GB10 (vllm#52393); lm-eval sends `stop` on every request.
- [Measured] **"Output-neutral by construction" instead of a diff.** A clock-cap sweep ("identical in shape"; [Clocks, thermal, power](13-clocks-thermal-power.md)), a TP1-to-TP2 move ("TP does not change the model") and a draft-vocabulary cut ("unchanged by construction") were all accepted without a token diff. [Community-measured] Even correct speculation agrees with non-speculative greedy only 47.7-97.3% of the time, so the diff is a measurement to interpret, not a byte-identity pass.
- [Community-measured] **A fusion A/B that tested nothing.** A GB10 flag A/B showed "no corruption" because zero fusion patterns matched (vllm#50773). Disabling the fusions in the original report restored well-formed but still off-instruction text, and the mechanism on SM12x is unexplained.
- [Community-measured] **Booking small acceptance deltas.** A 1-ulp kernel change moved acceptance ±10 points (vllm#54426); a -10.6% relative acceptance regression on one base inverted on the next (vllm#49927). Acceptance does not track judged quality (Spearman 0.19-0.25).
- [Community-measured] **Relaxed acceptance as a free speed-up.** Judge or lenient acceptance cost HumanEval 86.6% -> 80.4%. SGLang thresholds below 1.0 and vLLM `synthetic` rejection are quality changes.
- [Community-measured] **Scored items as a determinism instrument.** Uniform failure looks deterministic; the SGLang "ineffective on hybrid" verdict rests on that weaker instrument (sglang#36291). Use distinct completions with a must-fail control.
- [Community-measured] **Synthetic fixtures as proof of absence.** A synthetic look-alike fixture read 0/30 where the real replay read 11/30 at the same `index_topk`.
- [Community-measured] **Assuming a determinism flag works because it reports itself enabled** (sglang#36291), or because docs list the model: vLLM docs list a GDN hybrid as tested while the code at the pin refuses GDN backends in batch-invariant mode.
- [Community-measured] **Porting an SM120 fix to SM121.** SGLang's exact-SM120 sparse-decode gate excluded SM121 because forcing GB10 through it corrupted long contexts; GB10 needs sglang#36845.
- [Community-measured] **Assuming an upstream fix is in the running build.** MTP + prefix caching on hybrids was fixed for one mechanism in 0.26 (vllm#43559), still produced malformed output at 0.81% on 0.28.0 (vllm#53912), and a GB10 nightly silently disabled cache hits under speculation (vllm#54360). llama.cpp #28123 fixed snapshot coverage while a dirty-context rollback still fails. Check the fix against the overlay's base and gate the symptom, not the changelog.
- [Measured] **Uncalibrated FP8 KV treated as equivalent.** Two lanes run scale 1.0; gates and retrieval pass, which the packets themselves say does not prove equivalence to BF16 KV. [Community-measured] Off-GB10, FP8 KV paths have dropped 128K NIAH to 13% and a multi-turn judge score from 4.61 to 1.07 while single-turn looked fine.
- [Measured] **A degenerate state that outlives the request.** A `!` run under FP8 KV poisoned later unrelated requests through the prefix cache until restart [Community-measured reproduction]; separately, stored stunted turns in a client transcript re-poisoned new sessions [Measured]. Incident gates include one clean unrelated follow-up, and separate lane faults from client-transcript poisoning.
- [Measured] **Abliteration assumed to leave speculation and context intact.** The abliteration tool never edited the MTP head (byte-identical), so "speculation unaffected" was untested at k=2; one abliterated checkpoint shipped a tokenizer config that truncated context at 8,192 tokens. [Community-measured] A community recipe records a prebuilt abliterated EXL3 checkpoint as "an alternative checkpoint, not a quality-equivalent replacement" (higher teacher KLD per its model card), and off-target shifts of +7.4 to +12.2 pp on refusal-free decisions exist in the literature.
- [Measured] **Promotion ahead of the gate.** One lane was cut over before its packet established answer-quality parity; another's manifest reads "promoted" while its summary says "hold" pending a truncation baseline; a third was accepted unqualified by operator decision. Record undischarged gates on the lane card.
- [Measured] **Headlining a quick probe.** A 3-rep probe claiming +38% decode was withdrawn; the frozen harness showed no change. Compare only inside the frozen harness and a clean window.
- [Measured] **Composite metrics across protocols.** A tok/s from one protocol joined to acceptance from another, and a third party's unpatched per-position acceptance curve filed as own. One protocol per row.
- [Measured] **An answer key with every gold answer in option A.** A GPQA source file had all golds at A; options were shuffled deterministically and remapped. Check the gold distribution before scoring.
- [Community-measured] **Trusting an optimized quant without its own KLD.** ExLlamaV3's bitrate optimizer produced a recipe with worse KLD than the uniform baseline (exllamav3#108).
- [Community-measured] **Grammar-valid taken as correct.** Grammar backends emptied a required array and rewrote a string value (sglang#2216, 2024 build); constrained decoding produced 8/8 valid calls from models that never terminated (arXiv 2609.26693).
